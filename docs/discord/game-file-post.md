게임 zip(약 64MB)은 디스코드 무료 한도(10MB)를 넘어서 Google 드라이브에 올리고 링크를 붙여요.
아래 글의 `(여기에 드라이브 링크)` 를 복사한 링크로 바꿔서 올리면 돼요.

# 🎮 테스트 0.7 · Windows

### 📥 다운로드
**👉 (여기에 드라이브 링크)**
-# Google 드라이브 · 약 64MB · 디스코드 파일 한도(10MB)를 넘어서 드라이브에 올려요

### ▶️ 하는 법
**1.** 링크에서 zip 파일을 받아요 (드라이브 오른쪽 위 ⬇️ 다운로드)
**2.** 압축을 풀고 `GrannysKitchen.exe` 더블클릭
**3.** "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
-# 서명하지 않은 개발 버전이라 나오는 경고예요
-# "바이러스를 검사할 수 없습니다" 창이 뜨면 **무시하고 다운로드** (파일이 커서 나오는 안내예요)

### 🕹️ 조작
- 🖱️ 마우스 클릭
- 🎮 게임패드 — `A` 고르기 · `B` 뒤로 · 십자키 이동
- ⏸️ `Esc` 나 `Start` — 일시 정지 · 설정
