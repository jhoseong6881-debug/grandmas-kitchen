# 📐 포토샵으로 먼저 그릴 때 크기표

### 규칙
- **캐릭터·아이콘·요리·소품** → 포토샵 작업 크기 = 원본 × **8**
- **배경** → 포토샵 작업 크기 = **1920 × 1080** (원본 640×360 의 3배 = 게임 화면 그대로)
-# 정확한 배수로 그려야 줄일 때 비율이 안 틀어지고 점이 고르게 나와요

### ⭐1 크기표 — 포토샵 → 원본(Aseprite) · 게임 화면
🐾 **손님 5마리 (표정 4장씩)** `960×1280` → `120×160` · 화면 360×480
🦝 **너구리 상인** `576×704` → `72×88` · 화면 216×264
🌧️ **우비 입은 손님** `960×1280` → `120×160`
🎉 **잔치에 앉은 손님** `480×640` → `60×80`
🥕 **재료 아이콘** `128×128` → `16×16` · 화면 48×48
🍙 **완성 요리** `512×512` → `64×64` · 화면 192×192
🎁 **기념품** `344×344` → `43×43`
🌅 **배경** (텃밭·부엌·저녁 마당·타이틀…) `1920×1080` → `640×360`
-# 나머지 그림은 🎨그림-목록 의 원본 크기 × 8 로 잡으면 돼요

### 🖌️ 포토샵 → 도트 순서
**1.** 새 문서 — 위 작업 크기, 해상도 72, 배경 투명
**2.** 평소처럼 그리기 — 줄이면 아주 가는 선·작은 무늬는 사라지니 굵직하게
-# 팁: 보기 → 격자를 **8px 간격**으로 켜 두면 "한 칸 = 나중에 점 하나" 감이 와요
**3.** 이미지 → 이미지 크기 → **원본 크기**로 (비율 고정 ✅, 리샘플링: 쌍입방)
**4.** Aseprite 에서 정리 — 흐린 경계를 또렷한 점으로, 색은 명암 4~5단계씩 10~16색 안팎으로 정리하고 밤색 테두리 다시 찍기
**5.** 원본 크기 그대로 PNG 내보내기 (Resize 100%)
