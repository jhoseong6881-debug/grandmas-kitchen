[서버 꾸미기 순서] — 이 파일은 디스코드에 올리는 글이 아니라 따라 하는 안내예요.

1) 카테고리 만들기
   왼쪽 채널 목록 빈 곳 오른쪽 클릭 → 카테고리 만들기
   만들 카테고리 4개 (이름 그대로 복사):
     📌 안내
     🎨 그림 작업
     🎮 게임
     ☕ 쉼터

2) 채널 이름 바꾸고 카테고리로 옮기기
   채널 옆 ⚙️ → 이름 바꾸기. 채널은 끌어서 카테고리 안으로 옮겨요.

   📌 안내
     📢공지
     📝패치노트
     📌할-일          ← 새로 만들기
   🎨 그림 작업
     🎨그림-목록
     🖼️그림-올리기
     💬그림-피드백     ← 새로 만들기 (그림 보고 의견 나누는 곳)
   🎮 게임
     🎮게임-파일
     🐛버그-제보       ← 새로 만들기
   ☕ 쉼터
     ☕잡담            ← 새로 만들기
     🔊 작업-통화        ← 음성 채널로 만들기 (같이 얘기하며 작업할 때)

3) 채널 설명(주제) 넣기
   채널 ⚙️ → 개요 → 채널 주제 칸에 아래 "1_채널설명.txt" 의 한 줄씩 붙여 넣기

4) 안내 글 올리고 고정하기
   - 📢공지  : "2_공지_환영.txt"
   - 🖼️그림-올리기 : "3_그림올리기_안내.txt"
   - 🐛버그-제보 : "4_버그제보_안내.txt"
   올린 뒤 메시지에 마우스 → ⋯ → 메시지 고정 하면 채널 위 📌 에 늘 남아요.

5) (선택) 공지·패치노트·할-일은 읽기 전용으로
   채널 ⚙️ → 권한 → @everyone → "메시지 보내기" ❌
   (서버 주인은 그대로 쓸 수 있어요)

6) 서버 아이콘 바꾸기
   서버 이름 옆 ⌄ → 서버 설정 → 서버 프로필(또는 개요) → 아이콘 업로드
   파일: docs/discord/server_art/icon_rabbit_512.png (토끼, 추천) 또는 icon_carrot_512.png (당근)
   (디스코드가 동그랗게 잘라요. 나중에 게임 아이콘 그림이 오면 그걸로 바꿔요)

7) 이모지 올리기
   서버 설정 → 이모지 → 이모지 업로드
     emoji_rabbit_128.png → 이름: halmae_tokki   (채팅에서 :halmae_tokki:)
     emoji_carrot_128.png → 이름: danggeun        (채팅에서 :danggeun:)
   (이모지 이름은 영어·숫자·밑줄만 돼요)
   손님 그림이 올 때마다 하나씩 늘리면 좋아요 — 암탉, 다람쥐, 곰, 고슴도치

8) 역할(이름 색) 만들기
   서버 설정 → 역할 → 역할 만들기. 만들고 사람에게 붙이면 대화창 이름 색이 바뀌어요.
     🧑‍🍳 주방장      #C8662B (당근색)   — 개발
     🎨 그림 장인     #6E9F5A (잎 초록)  — 그림
     🍚 맛보기 손님   #D9A441 (꿀색)     — 테스트해 주는 친구들
     🤖 콩이들        #8C7B6B (도토리색) — 패치콩·그림콩·플레이콩·새 봇
   역할 설정에서 "온라인 멤버와 따로 표시"를 켜면 오른쪽 멤버 목록이 역할별로 나뉘어요.

9) 새 봇(디스코드 플러그인) 이름과 사진
   개발자 포털 → 내 앱 → General Information 에서 이름과 사진을 바꿀 수 있어요.
   추천 이름: 제보콩 🐛 (버그 제보를 읽는 봇) · 사진은 이모지 그림(emoji_rabbit_128.png)을 써도 돼요.
   봇은 🐛버그-제보 채널만 읽게 하는 걸 추천해요.

10) 고친 글 다시 올리기
   📢공지 의 예전 환영 글을 "2_공지_환영.txt" 새 글로 바꿔 고정
   🐛버그-제보 의 고정 양식을 "4_버그제보_안내.txt" 새 글로 바꿔 고정 (버전 칸이 바뀌었어요)
