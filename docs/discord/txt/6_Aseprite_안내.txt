# 🧩 Aseprite로 그리는 법 (3배 기준)

### 💡 원리 — "게임이 점 하나를 3×3으로 키워요"
- Aseprite에서 찍는 **점 1개** → 게임 화면에서는 **가로 3 × 세로 3칸**으로 커져요
- 토끼를 `120×160` 파일에 그리면 → 게임에서는 `360×480` 로 보여요
- 키우는 건 게임이 해요. **원래 크기로만 그리면 돼요**

### 📐 640×360 은 뭐예요?
**화면 전체를 점 단위로 잰 크기**예요.
- 화면을 꽉 채우는 **배경**(텃밭, 부엌, 저녁 마당, 프롤로그…)만 `640×360` 판에 그려요
- **손님, 재료, 요리, 도구**는 각자 **자기 크기의 작은 판**에 따로 그려요 (배경 위에 얹는 건 게임이 해요)
- 🎨그림-목록 에 적힌 숫자 = **그 그림 파일의 판 크기**

🐰 토끼 손님 → `120×160`
🥕 당근 아이콘 → `16×16`
🍙 김밥 완성 그림 → `64×64`
🌅 아침 텃밭 배경 → `640×360`

### 🖌️ 순서
**1.** File → New → Width·Height 에 그릴 크기 (예: `120` × `160`) · Color Mode **RGBA** · Background **Transparent**
**2.** 판이 작으면 **확대**해서 그려요 (마우스 휠 / 800% 정도) — 보는 크기만 커지고 그림 크기는 그대로예요
**3.** 연필(**B**), 브러시 **1px** 로 점 하나씩
**4.** File → **Export As…** → **PNG**, Resize 는 **100%** 그대로 (300% ❌ — 키우는 건 게임이)
**5.** 영어 파일 이름 (예: `rabbit.png`) → 🖼️그림-올리기 에 올리기

### ❓ 자주 헷갈리는 것
**그림이 너무 작은데요?** → 정상이에요! 확대해서 그리고, 저장은 원래 크기로
**640×360 판에 토끼를 그려도 돼요?** → 분위기 보는 용도로는 OK. 제출은 토끼만 `120×160` 파일로 따로
**딱 그 크기여야 해요?** → 1~2칸 달라도 괜찮아요. 게임 쪽 칸은 제가 맞출게요
