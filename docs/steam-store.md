# 스팀 상점 페이지 준비물 (초안)

2026-10-08 정리. 그림 규격은 스팀 공식 문서(Steamworks: Store Graphical Assets, Library Assets)에서 확인했다.
스팀은 규격을 가끔 바꾸므로, 실제로 올리기 전에 Steamworks 화면에서 한 번 더 확인한다.

## 1. 상점 그림

도트 그림이라 원본을 작게 그리고 **정수배(2배·3배·4배)로 nearest 확대**하면 된다. 아래 "원본 제안"은 그 크기.
캡슐 그림에는 **게임 제목(로고) 말고 다른 글자(평점, 문구, "데모" 같은 말)를 넣으면 안 된다.**

| 그림 | 크기 (스팀) | 원본 제안 | 필수 | 규칙 |
|---|---|---|---|---|
| 헤더 캡슐 (Header Capsule) | 920×430 | 460×215 (2배) | 필수 | 로고가 잘 읽혀야 함. 제목 말고 다른 글자 금지 |
| 작은 캡슐 (Small Capsule) | 462×174 | 231×87 (2배) | 필수 | 로고가 거의 꽉 차게. 가장 작게(120×45) 줄어도 읽혀야 함 |
| 메인 캡슐 (Main Capsule) | 1232×706 | 616×353 (2배) | 필수 | 상점 첫 화면 큰 그림. 로고 잘 읽히게 |
| 세로 캡슐 (Vertical Capsule) | 748×896 | 374×448 (2배) | 필수 | 계절 할인 때 쓰임 |
| 상점 배경 (Page Background) | 1438×810 | 719×405 (2배) | 선택 | 은은하게 (내용을 가리지 않게). 없으면 마지막 스크린샷으로 자동 생성 |

## 3. 게임 아이콘

- 지금 실행 파일·맥 앱 아이콘이 Godot 기본 아이콘(icon.svg)이다. 게임 아이콘 그림이 필요하다.
- 원본 64×64 (또는 32×32) 도트 → 256×256·1024×1024 로 정수배 확대해서 쓴다. 배경 투명.
- 그림이 오면: project.godot 의 config/icon, 윈도우 내보내기 application/icon(.ico), 맥 내보내기 아이콘에 넣는다.

## 4. 스크린샷

- 1920×1080 이상, 16:9. **최소 5장.** 게임 화면만 (콘셉트 그림·영상 장면 금지). 4장 이상은 "모든 연령에 적합"으로 표시.
- 지금은 임시 도형이 많아서, 손님 넷·부엌 배경·재료 아이콘이 들어온 뒤에 찍는 것을 추천한다.
- 후보 장면: ① 아침 텃밭 ② 부엌에서 손님 주문 ③ 미니게임(볶기 또는 부치기) ④ "완성~!" 장면 ⑤ 저녁 평상 이야기 ⑥ 봄 잔치
- 찍는 도구(시험용 화면 찍기 봇)가 있어서, 그림이 들어오면 같은 장면을 바로 다시 찍을 수 있다.

## 5. 소개 글 초안 (한국어)

**짧은 소개** (상점 맨 위, 300자 이내)
> 도시에 지친 손주가 돌아가신 할머니의 숲속 밥집을 다시 엽니다. 동물 이웃들에게 밥을 지어 주고, 돈 대신 받은 재료로 새 요리를 배우며, 저녁 평상에서 할머니가 남긴 레시피와 이야기를 한 장씩 되찾는 느긋한 요리 경영 게임.

**긴 소개**
> 새벽 한 시, 마지막 지하철. 언제부터 이렇게 웃지 않았는지 모를 손주에게 숲골 마을에서 전화가 옵니다.
> 할머니가 남긴 것은 녹슨 열쇠 하나와, 페이지가 모두 뜯겨 나간 레시피 공책 하나.
>
> 숲속 할머니 집 한쪽의 작은 밥집을 다시 열면, 할머니 밥을 그리워하던 동물 이웃들이 하나둘 찾아옵니다.
> 손님들은 돈 대신 자기가 가진 재료를 밥값으로 내고, 새 재료로 새 요리를 배울 수 있어요.
> 그리고 저녁마다 평상에 앉아 이웃들의 이야기를 듣다 보면, 이웃들이 맡아 두었던 할머니의 레시피가 한 장씩 돌아옵니다.

**특징**
- 🍳 **요리 미니게임 8가지** — 썰기, 볶기, 부치기, 말기, 밥 짓기, 버무리기, 조리기, 다지기. 요리마다 손맛이 달라요
- 🥕 **물물교환 밥집** — 밥값은 재료로. 손님을 잘 대접하면 새 재료와 새 레시피가 열려요
- 🐰 **동물 손님 다섯** — 저마다 좋아하는 맛과 숨겨 둔 사연이 있어요
- 📖 **할머니 레시피 노트** — 할머니 비법대로 요리하면 "할머니 손맛"
- 🌱 **아침 텃밭과 숲속 장터** — 당근을 기르고, 버섯 원목을 돌보고, 닷새마다 너구리 상인과 거래해요
- 🌙 **저녁 평상** — 하루를 마치며 이웃들과 나누는 이야기, 그리고 봄의 끝에 열리는 잔치
- 🎮 **실패도 시간 제한도 없는 느긋한 게임** — 마우스와 게임패드 모두 지원

데모: 봄 15일, 약 1시간 40분~2시간.

## 7. 최소 사양 초안 (확인 필요)

- 윈도우: Windows 10 64비트, 듀얼 코어 프로세서, 메모리 4GB, 그래픽 DirectX 12 또는 Vulkan 지원, 저장 공간 300MB
- 맥: macOS 11 이상 (인텔·애플 칩 모두), 메모리 4GB, 저장 공간 300MB
- 실제 사양은 낮은 사양 컴퓨터에서 직접 돌려 보고 정한다. 지금 실행 파일 크기는 약 145MB.
