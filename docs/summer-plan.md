# 여름 계획 (2026-10-05)

봄이 끝나면 바로 이어지는 두 번째 계절. 큰 그림은 봄 → 여름 → 가을 → 겨울.
그림을 기다리는 동안 먼저 만든다. 한 번에 하나씩, 끝날 때마다 확인하고 커밋한다.

## 정한 것
- **넘어가기**: 봄 잔치(할머니 편지) 뒤 "여름이 왔어요" → 여름 1일째 아침. 재료·레시피·단골·가게 단계·기념품은 그대로 이어진다.
- **길이**: 15일 (날짜는 여름 1일째부터 다시 센다). 약 80분.
- **여름 손님**: 봄 손님과 다른 손님 5~6명 (성격·밥값·대사는 초안을 보고 정한다. 새 손님 체크리스트를 꼭 지킨다: 첫 만남 인사, 입맛 힌트, 평상 첫인사, 1일째 부탁 없음)
- **텃밭**: 여름 작물로 바꾼다 (봄 작물 대신 심을 수 있는 작물 목록이 계절마다 다르다)
- **낚시터**: 버섯 원목 자리를 **숲속 호수/연못 낚시터**로 바꾼다
  - 쿼터뷰 화면. 조그만 내가 물가로 걸어가서, 낚싯대를 주섬주섬 꺼내, 찌를 던진다
  - 미끼: 기본 미끼가 있고 바꿀 수 있다. **미끼 쓰는 횟수로 하루 낚시를 제한**한다
  - 물고기가 물 때까지 기다렸다가, 스타듀밸리처럼 낚아 올리는 미니게임
  - 민물고기 (예: 붕어, 메기, 잉어, 송어 …)
- **도감**: 물고기와 채소 재료를 모으는 책 (처음 얻으면 칸이 채워진다)
- **거센 비 오는 날**: 손님이 오지 않고, 좋은 물고기가 잘 낚이는 낚시의 날 (봄비 기능을 다시 쓴다)
- **새 미니게임 3개**: 빙수 갈기, 숯불 생선 굽기, 수박 자르기 (손맛은 하나씩 만들 때 정한다)
- **여름 레시피 노트**: 여름 손님들이 할머니 노트를 한 장씩 돌려준다
- **여름 끝**: 15일째 **낚시 대회**
- **음악**: 여름 곡들 (중국풍 단어 없이)

## 만드는 순서 (하나씩)
1. ✅ **계절 구조 정리** (data/seasons/spring.tres, summer.tres · SeasonData) — 지금 봄에 묶인 것(봄 잔치, 봄 곡 목록, 봄비, "봄 완료", 장소·작물·손님)을 계절마다 데이터 하나로. 봄 잔치 → 여름 1일째로 넘어가기
2. **여름 텃밭 작물**
3. **낚시터 1** — 장면, 쿼터뷰로 걸어가기 → 찌 던지기 → 기다리기 → 입질
4. **낚시터 2** — 낚아 올리는 미니게임 (스타듀밸리식), 물고기 데이터
5. **미끼** — 기본 미끼와 바꾸기, 하루 횟수 제한
6. **도감**
7. **거센 비 오는 날**
8. **여름 손님 5~6명** (초안 먼저)
9. **여름 레시피와 노트** + **새 미니게임 3개** (빙수 갈기, 숯불 생선 굽기, 수박 자르기)
10. **여름 저녁 이야기와 할머니 회상**
11. **낚시 대회** (여름 끝)
12. **여름 음악**, 자동 플레이로 균형 점검

## 아직 정할 것
- 봄 손님 다섯은 여름에도 오는지 (안 오면 어디 갔는지 한 줄 이유)
- 여름 작물 종류, 물고기 종류와 밥값 재료
- 장터는 여름에도 닷새마다 열리는지, 무엇을 바꾸는지
- 낚시 대회 규칙 (가장 큰 물고기? 정해진 시간 동안 많이?)
