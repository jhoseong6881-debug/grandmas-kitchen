# 스팀덱 화면 점검 (2026-10-08)

스팀덱 화면은 1280×800 (16:10). 게임 기준은 1920×1080 (16:9).
맥에서 시험용 사본을 **1280×800 창**으로 띄워서 봄 15일을 자동으로 끝까지 플레이하며 화면 254장을 찍고,
봇이 들르지 않는 화면(처음 화면, 설정, 만든 사람들, 이야기 다시 보기, 손님 수첩, 목표판, 메뉴판, 일시 정지, 봄 잔치 전체, 데모 끝 인사)을 따로 찍었다.
화면 사진(일부)은 `build/steamdeck_check/` 에 있다 (Git 에는 안 올라감).

**실제 스팀덱 기기로는 해 보지 않았다.** 창 크기만 스팀덱과 같게 맞춘 시험이다.

## 지금 설정이 스팀덱에서 하는 일

- `window/stretch/mode="canvas_items"`, `aspect="expand"` → 1280×800 에서는 게임 화면이 **1920×1200** 으로 늘어난다 (세로 120 이 더 생김).
- 화면 전체가 2/3 로 줄어든다. 3배로 키운 그림은 결국 **원본의 정확히 2배**가 되어 도트가 또렷하다 (토끼 그림 확인).
- 늘어난 세로 120 은 위·아래에 붙은 버튼과 배경이 잘 나눠 가졌다. **빈 띠, 잘림, 겹침은 찾지 못했다.**

## 글자 크기 (밸브 기준: 가장 작은 글자 9픽셀 이상, 12픽셀 이상 권장)

| 글자 | 게임 안 크기 | 스팀덱에서 잰 높이 | 판정 |
|---|---|---|---|
| 기본 글자 (대사, 버튼) | 36 | 약 21~22픽셀 (24 글자를 잰 값으로 계산) | ✅ |
| 작은 글자 (가진 재료, 메뉴판 설명, 만든 사람들, 잔치 이름표, 수첩 버튼) | 24 | 약 14~15픽셀 | ✅ 권장 12 넘음 |
| **기념품 선반 이름** (기념품 그림이 없을 때만 나오는 임시 글자) | **12** | **약 8픽셀** | ❌ 9 미만, 글자가 뭉개져 읽기 어렵다 |

## 찾은 것

1. **기념품 선반 임시 이름 글자가 너무 작다** (`scripts/kitchen/shop_decor.gd` 의 `slot_font_size = 12`)
   - 스팀덱에서 약 8픽셀이라 "할머니의 꽃무늬 손수건" 같은 글자가 뭉개진다. PC(1920×1080)에서도 12픽셀이라 작다.
   - 기념품 그림(아이콘)이 들어오면 이 글자는 사라진다. 그 전까지만의 문제.
   - 고치는 방법 후보: 글자를 24로 키우고 칸 안에서 두 줄로 줄바꿈 / 그림이 올 때까지 짧은 이름(예: "손수건")만 보이기.
2. **작은 글자(24)의 획 굵기가 들쭉날쭉하다** (보기 문제, 읽기는 됨)
   - 도트 글꼴은 12픽셀 격자라서, 36 글자는 스팀덱에서 정확히 2배(또렷), 24 글자는 1.33배가 되어 획이 1칸·2칸으로 섞인다.
   - 고치는 방법 후보: 작은 글자를 24 대신 36으로 (자리 부족한 곳이 생김) / 그대로 두기. 급하지 않다.
3. **창 모드**: 게임이 기본으로 창 모드(1920×1080 창)로 켜진다. 스팀덱 게임 모드에서는 보통 화면에 맞춰 주지만, 16:9 로 잡혀 위아래 검은 띠가 생길 수 있다.
   - 실제 기기에서 확인 필요. 띠가 생기면 스팀덱에서만 처음부터 전체 화면으로 켜기 (스팀이 스팀덱에서 `SteamDeck` 환경 변수를 준다고 알려져 있음, 확인 필요).
4. **이름 짓기**: 이름 칸에 기본 이름이 미리 적혀 있고 게임패드 A 로 바로 정할 수 있다. 직접 글자를 치려면 스팀덱에서 STEAM + X 로 화면 키보드를 열어야 한다 (docs/ideas.md 에 이미 있음: 스팀 출시 때 GodotSteam 의 게임패드 글자 입력).

## 같이 확인한 것

- 1280×800 자동 플레이 1번: 15일 끝까지, 감시 2822번·저장 파일 확인 16번 모두 문제 없음.
- 봄 잔치 → 노트 정리 → 할머니 편지 → 마지막 한 줄 → "봄이 지나갑니다" → 데모 끝 인사 → 처음 화면("봄 완료")까지 스크립트 오류 0개.

- 게임 모드에서 화면이 꽉 차는지, 검은 띠가 생기는지
