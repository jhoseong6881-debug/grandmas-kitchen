# 게임 방향 다시 잡기 (2026-10-02 첫 플레이 피드백 이후)

## 피드백
- 점심이 너무 반복된다.
- 왜 내가 할머니 식당에서 요리하는지 모르겠다. 내가 할머니인지 나인지 헷갈린다.
- 요리마다 레시피(써는 횟수, 볶는 횟수 등)가 더 달랐으면 좋겠다.
- 지금은 쿠킹마마와 다를 게 없다. 차별성이 필요하다.
- 점점 번창하는 가게로 도파민을 채워 주면 좋겠다.

## 정한 방향
- **주인공**: 돌아가신 할머니의 손주. 프롤로그 끝에 이름을 짓는다. 손님들은 이름이나 "할머니 손주"로 부른다.
  할머니는 늘 3인칭("할머니")으로만 나온다.
- **차별성 = 할머니 비법 + 손님 맞춤 요리**
  - 할머니 비법: 레시피마다 할머니만의 숨은 손맛이 있다 (예: "전은 한 번 더 노릇하게", "꿀은 마지막에").
	저녁 손님 이야기에서 힌트를 듣고, 그대로 요리하면 "할머니 손맛" 완성. 손님이 할머니를 떠올리며 특별하게 반응한다.
	요리가 손재주 시험이 아니라 "할머니를 기억해 내는 일"이 된다.
  - 손님 맞춤 요리: 손님마다 취향이 있다 (곰은 달게, 고슴도치는 바삭하게 등).
	요리를 마무리할 때 취향에 맞추면 단골도가 오른다. 취향은 대접하면서 알게 되고 손님 수첩에 적힌다.
- **번창**: 손님을 대접할수록 "소문"이 쌓이고, 가게가 단계별로 커진다 (간판 → 테이블 추가 → 새 조리도구 → 꾸미기).
  하루가 끝나면 장사 결과 화면에서 오늘 번 것과 소문을 보여 준다.
- **레시피마다 다르게**: 요리 단계를 데이터로 정한다. 단계마다 미니게임 종류뿐 아니라 재료, 횟수, 빠르기가 다르다.
  예: 김밥 = 밥 짓기 → 당근 채썰기 12번(빠르게) → 당근 볶기 3번 → 김밥 말기 → 김밥 썰기 8번 → 담기

## 만드는 순서 (한 번에 하나씩)
1. 프롤로그 + 이름 짓기 (개연성)
2. 레시피마다 다른 요리 단계 (횟수, 빠르기, 재료) — 반복감 줄이기, 3~5의 바탕
3. 할머니 비법 (힌트 → 비법대로 요리 → 할머니 손맛)
4. 손님 취향과 단골도
   - 4-1. 마무리 고명(data/garnishes/)과 손님 입맛, 단골도 점수와 단계(낯선 손님 → 이웃 → 단골 → 식구), 수첩 하트
   - 4-2. 단골 보상: 단계가 오르면 밥값이 늘고, 단골 선물, 새 저녁 이야기
   - 4-3. 오늘의 부탁: 손님이 가끔 "바삭하게요" 같은 부탁 (그날만 생기는 목표 자리)
   - 4-4. 손님 수첩 모으는 재미 (2026-10-10, 피드백 "수첩을 열어 볼 마음이 안 생긴다"):
     ① 손님 얼굴 그림, 못 만난 손님은 실루엣과 "?" ② 좋아하는 요리는 그 손님에게 대접해야 한 칸씩 적힘,
     싫어하는 요리는 대접해 봤거나 이웃(RegularSettings.dislike_reveal_tier)이 되면 털어놓음, "알아낸 것 4/9", 다 알면 ★
     (세이브 guest_known_dish_ids, 옛 세이브는 만난 손님 것을 모두 아는 것으로) ③ 대접하고 새로 적힌 게 있으면 손님 위에 "수첩에 새로 적었어요!" (소리 book) + 수첩 버튼 ●
5. 하루 끝 장사 결과 화면 + 소문
6. 가게 단계 업 (간판, 테이블, 조리도구, 꾸미기)
