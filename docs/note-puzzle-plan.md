# 번진 할머니 노트 퍼즐 (기획, 2026-10-09)

사용자 결정: 벤바(Venba)의 "번진 요리책 퍼즐"을 우리 게임에 맞게 만들어 **레시피 10개 모두**에 넣는다.
봄 기능 동결(docs/roadmap-2026-10.md)의 예외로 사용자가 정했다.

**참고만 하고 베끼지 않는다**: 규칙(번진 칸을 생각해서 채우기, 실패해도 손해 없음, 추억이 힌트)만 참고한다.
벤바의 그림·화면 배치·문제 내용·글은 쓰지 않는다. 문제는 모두 한국 집밥 요령과 우리 할머니 이야기로 새로 만든다.

## 왜 우리 게임에 맞나

- 우리 이야기 자체가 "할머니 레시피 노트를 한 장씩 되찾기"다. 되찾은 노트가 오래돼서 **몇 칸이 번져 있다**는 설정이 자연스럽다.
- 지금 미니게임은 손재주(타이밍)만 묻는다. 퍼즐은 **"할머니라면 어떻게 하셨을까"** 를 묻는다. 손이 서툰 사람도 즐길 거리가 생긴다.
- 기존 "할머니 비법"(미니게임 타이밍 자리)과 겹치지 않는다. 비법은 손맛, 퍼즐은 요령.

## 흐름

1. 점심에 손님이 주문한 요리를 **처음** 만들 때 (퍼즐을 아직 안 푼 요리), "요리하기"를 누르면 미니게임 전에 **할머니 노트**가 펼쳐진다.
2. 노트에는 레시피가 손글씨로 적혀 있고, **1~3칸이 번져** 있다.
3. 오른쪽 조리대에서 번진 칸을 채운다 (아래 두 가지 방식).
4. 다 채우면 번진 자국이 스르르 걷히고 노트가 깨끗해진다 → 바로 평소 미니게임이 이어진다.
5. 푼 퍼즐은 저장된다. 다음부터 그 요리는 바로 미니게임.

**지키는 것**
- **실패 없음**: 틀리면 재료가 톡 튀어 돌아오고 할머니 말투 한 줄("음… 이건 조금 나중이었던 것 같은데")만 나온다. 재료가 줄거나 점수가 깎이지 않는다.
- **힌트**: 노트 옆 "추억 떠올리기" 버튼 → 할머니가 하시던 말씀 한 줄. 두 번 틀리면 저절로 떠오른다.
- **1일째에는 퍼즐 없음** (처음 15분이 무거워지지 않게). 2일째부터.
- **점심 한 번에 퍼즐은 하나까지** (소풍 도시락 날처럼 여러 요리를 하는 날에도 줄줄이 나오지 않게). 나머지는 다음에 만들 때.
- 마우스·게임패드 모두: 재료 카드와 고르기 칸은 모두 버튼이라 십자키 + Ⓐ 로 된다. 마우스는 끌어다 놓기도 된다 (2단계에서).
- 손님은 그동안 기다린다 (요리 중에는 손님이 감춰져 있어서 기다리는 압박이 없다).

## 퍼즐 방식 두 가지 (데이터로 만든다)

| 방식 | 하는 일 | 화면 |
|---|---|---|
| **넣는 순서** | 노트의 번진 순서대로 재료를 냄비·그릇·팬에 하나씩 넣는다 | 재료 카드 3~5장 (가짜 카드 1장 포함) |
| **빈칸 고르기** | 번진 낱말 하나를 고른다 (불 세기, 물 양, 넣는 때, 방법) | 고르기 칸 2~3개 (불 손잡이·계량 컵 같은 모양은 그림이 오면) |

재료 카드는 게임 재료(당근·도토리·계란·버섯·꿀) + **부엌 기본양념**(소금·참기름·간장·깨·물·밀가루·도토리가루). 기본양념은 퍼즐에서만 쓰는 소품이라 가진 재료가 줄지 않는다.

## 레시피 10개 퍼즐 (초안 — 사용자가 확인·고칠 것)

| 요리 | 번진 칸 | 답 | 힌트 (할머니 말씀) |
|---|---|---|---|
| 🍙 할머니표 당근 김밥 | 고르기: "썰기 전에 칼에 ▒▒▒을 바른다" (물 / 참기름 / 꿀) | 참기름 | "칼에 기름칠을 해야 김밥이 안 뭉개지지" |
| 🥕 꿀 당근 조림 | 순서: 당근 → 물 → **꿀** / 고르기: "꿀은 ▒▒▒ 넣는다" (처음에 / 마지막에) | 꿀은 마지막에 | "꿀은 오래 끓이면 쓴맛이 나. 불 끄기 전에 쪼르륵" |
| 🍳 당근 계란 볶음 | 순서: 기름 → **당근** → **계란** (가짜: 꿀) | 단단한 당근 먼저 | "단단한 것부터 볶는 거여" |
| 🍄 숲속 버섯 볶음 | 고르기: "버섯은 ▒▒에 씻지 말고 마른 행주로 턴다" / "소금은 ▒▒▒" (처음에 / 다 볶고) | 물에 · 다 볶고 | "버섯은 물을 먹으면 맛이 도망가" |
| 🥗 도토리묵 무침 | 고르기: "양념은 ▒▒으로 살살" (숟가락 / 손 / 거품기) | 손 | "묵은 여려서 손으로 살살 달래야 해" |
| 🍯 도토리 꿀강정 | 고르기: "꿀은 ▒▒▒ 늘어질 때까지 졸인다" (물처럼 / 실처럼 / 돌처럼) · 순서: 꿀 졸이기 → 도토리 → 펴서 식히기 | 실처럼 | "숟가락으로 떠서 실이 주욱 늘어지면 됐다" |
| 🍲 버섯 도토리묵밥 | 순서: 밥 → 묵 → 버섯 → **국물** / 고르기: "봄 국물은 ▒▒▒" (따뜻하게 / 차갑게) | 따뜻하게 | "여름엔 시원하게, 쌀쌀한 봄엔 따끈하게" (여름에 답이 바뀌는 재미) |
| 🥞 할머니표 당근 도토리전 | 순서: 당근 → 도토리가루 → 계란 (가짜: 꿀) / 고르기: "전은 ▒▒ 뒤집는다" (한 번만 / 여러 번) | 한 번만 | "자꾸 뒤집으면 전이 운다" (전 부치기 뒤집개와 이어짐) |
| 🥚 꿀 계란말이 | 고르기: "불은 ▒▒" (센불 / 약불) | 약불 | "계란은 성질이 급해서 약불에 달래야 해" |
| 🍄 버섯 계란전 | 순서: 버섯 → **가루** → **계란물** | 가루 먼저 | "가루옷을 입혀야 계란이 착 붙어" |

요리 지식은 흔히 알려진 집밥 요령으로 골랐다. 사용자(또는 집안 어른)가 보기에 "우리 할머니는 이렇게 안 하셨는데" 싶은 칸은 고친다.

## 보상

- 노트가 깨끗해지면 "할머니 노트를 다 읽었어요" + 노트 넘기는 소리.
- 저녁 평상의 레시피 노트(펼친 할머니 노트)에도 그 요령 한 줄이 손글씨로 더해진다.
- 점수·돈 보상은 넣지 않는다 (요령을 아는 기쁨이 보상. 코지 방향).

## 데이터 설계 (코드에 문제를 박지 않는다)

- `NotePuzzle` (Resource): 노트 줄 목록, 힌트 한 줄
- `NotePuzzleLine` (Resource): 방식(넣는 순서 / 빈칸 고르기), 앞뒤 글, 정답, 보기(가짜 포함), 틀렸을 때 한 줄
- `Recipe.note_puzzle` (선택 칸, 비면 퍼즐 없음 → 여름 레시피는 나중에 채우면 된다)
- 부엌 기본양념은 `data/pantry/*.tres` (이름·색·아이콘 칸)
- 세이브: `solved_note_puzzle_ids` (예전 세이브는 빈 목록 → 그대로 이어짐)

## 만드는 순서 (한 번에 하나씩)

1. 데이터 틀 + 세이브 칸 + 노트 퍼즐 창 + **빈칸 고르기** 방식 → 꿀 계란말이 하나로 시험
2. **넣는 순서** 방식 → 당근 계란 볶음으로 시험
3. 10개 퍼즐 데이터 채우기 + 1일째 없음·점심 한 번 규칙
4. 추억 떠올리기(힌트), 노트 깨끗해지는 연출, 저녁 노트에 요령 한 줄, 소리
5. 마우스 끌어다 놓기
6. 점검: 자동 플레이 봇(퍼즐 자동 풀기 추가), 게임패드만, 스팀덱 화면, 옛 세이브

## 그림 (디자이너님께, 없어도 동작)

- 번진 자국(잉크 번짐) 몇 가지, 노트 펼친 모습은 기존 그림 칸(recipe_note_book) 재사용
- 기본양념 아이콘 16x16: 소금·참기름·간장·깨·물·밀가루·도토리가루
- 냄비·그릇은 미니게임 도구 그림을 같이 쓴다
